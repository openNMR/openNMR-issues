# openNMR-issues
Welcome to the openNMR issue tracker!

This public repo is to be used for declaring issues, bugs and requested changes to openNMR

The openNMR source code is currently maintained in a private repository - this will (eventually) change.

This public repository is provided for users of openNMR to:

- Report bugs and problems.
- Suggest new features and improvements.
- Discuss possible solutions.
- Report issues encountered when using the software.

## How to report a problem

1. Go to the [Issues](https://github.com/openNMR/openNMR-issues/issues) page.
2. Click "New issue".
3. Give your issue a descriptive title.
4. Describe the problem, including steps to reproduce it where possible.

You need a GitHub account to submit an issue.

## Issue status

Issues will be reviewed and classified by the "developers" of the code.

When an issue has been resolved, it will be closed, with a comment indicating the relevant software version where appropriate.

Thank you in advance for helping improve openNMR!
